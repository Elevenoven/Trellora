# Plan-and-Execute ReAct Fixture

## 基础事实

当前项目的数据库迁移工具是 Flyway。

当前笔记索引版本是 current-note-structure-v1。

SpringBoot 服务的默认端口是 8080。

NER 表示命名实体识别（Named Entity Recognition）。

发布版本固定记录为 1.2.3。

## 术语与词法

NER 是文档中唯一明确写出的命名实体识别缩写。

SpringBoot 的启动端口仍然是 8080。

RAG 检索链路只接受明确写出的术语，不把 RBG 当作 RAG 的静默别名。

命名实体识别由本地词法索引按单字和双字词元召回。
