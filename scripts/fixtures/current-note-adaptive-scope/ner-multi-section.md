# NER 多章节范围夹具

本夹具只用于冻结当前笔记词法检索的阶段 0 基线，不代表对答案或引用的断言。

## NER 定义

NER 是 Named Entity Recognition（命名实体识别），用于从文本中识别人员、组织、地点等实体，并判断实体类别。

## NER 并非传统规则匹配

NER 不是只依赖人工规则的传统字符串匹配；规则可以辅助，但不能替代模型对上下文的识别。

## NER 模型分类

| 分类 | 说明 |
| --- | --- |
| 规则与词典方法 | 使用领域词典和可维护规则。 |
| 序列标注模型 | 使用 CRF、BiLSTM-CRF 等模型对 token 序列分类。 |
| Transformer 模型 | 基于预训练语言模型进行上下文实体识别。 |
| spaCy 工具链 | 使用 spaCy 的实体管线快速搭建可维护的 NER 处理流程。 |
| LLM 增强 | 使用 LLM 辅助难例分析和标注反馈，但仍需由 NER 原文证据校验。 |

## NER 数据标注

NER 数据标注要统一实体边界、实体类型和嵌套实体的处理规范；训练集与测试集必须使用相同标注口径。

## NER 评估

NER 评估通常报告 Precision、Recall 和 F1，并按实体类型分析边界错误与类别混淆。

## NER 部署

NER 部署需要关注模型延迟、词表版本、领域漂移、监控指标和人工反馈闭环。
