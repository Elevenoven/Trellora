# Provider icons

Bundled SVG assets for offline display. Logos retain their upstream artwork.

- Lobe Icons: https://github.com/lobehub/lobe-icons/tree/79b551cf26aab9ea4ac701fb807160950a5b860f/packages/static-svg/icons (MIT; see LICENSE.lobe-icons).
- DuckDuckGo: https://github.com/simple-icons/simple-icons/blob/1089fb7d2bf0e323f834c205ab76265005a6d5e8/icons/duckduckgo.svg (CC0; see LICENSE.simple-icons).

Monochrome marks use a CSS mask to follow the application theme. Colour marks retain their original colours. Brand names and logos belong to their respective owners.
