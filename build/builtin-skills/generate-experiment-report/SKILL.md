# 实验报告生成

基于知识库中指定文档（实验记录、数据说明、操作手册等）生成结构完整的实验报告。目标是忠实还原已记录的实验过程与结果，缺口如实标注，绝不补造数据。

## 工作方式

1. 先确认报告来源：用户指定的文档要用工具实际读取，覆盖实验目的、步骤、数据与结论相关章节；多篇文档时分别读取并注明各自贡献。
2. 未指定文档时，列出检索到的候选文档标题让用户确认，不擅自选择。
3. 按报告模板组织内容，模板参考本技能附加文件 `templates/实验报告模板.md`，可用 read_skill 的 file_path 读取。
4. 区分三类信息并分别呈现：资料中直接记录的事实、由数据合理推断的结论、资料未覆盖的缺口；推断必须写明推断依据。

## 产出结构

按模板组织，至少包含：

1. **实验目的**：从资料中提炼，无法确认时标注「资料未明确」。
2. **实验环境与方法**：设备、参数、步骤，均来自资料记录；缺失项如实留空并标注。
3. **结果与数据**：只呈现资料中出现的数据与现象；有表格数据的按原值转述，不做外推与修约（除非资料说明修约规则）。
4. **分析与结论**：区分「资料给出的结论」与「基于数据的推断」，后者逐条附依据。
5. **缺口与建议**：列出报告所需但资料缺失的信息，以及补充哪类记录最有效。

## 约束

- 严禁编造或推测资料中不存在的实验数据、参数与结果；宁可标注「资料未记录」。
- 数据与结论必须可回溯：每个关键结果注明出处（《文档标题》—「章节」）。
- 资料间数据冲突时如实并列展示，说明分歧点，不挑选其一作为结论。
- 只生成报告内容供用户保存，不修改知识库原始文件。
