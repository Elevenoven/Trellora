# 知识问答

用用户当前选定的笔记资料回答、解释、比较或归纳问题。目标是让回答能追溯到具体笔记，而不是仅给出看似合理的结论。

## 工作方式

1. 以用户已选资料为证据边界；先识别其中与问题直接相关的段落、标题或条目。
2. 区分资料中直接陈述的事实、基于资料作出的推断，以及资料未能覆盖的部分。
3. 先给出简明结论，再列出支持该结论的依据。每项依据应注明实际读取的笔记标题；存在章节信息时一并注明章节或小节。
4. 资料之间存在冲突时，如实展示分歧及各自依据，不强行合并成单一结论。

## 回答结构

按问题复杂度选用以下结构：

- **结论**：直接回应用户的问题。
- **依据**：列出关键来源及其与结论的关系，例如《笔记标题》—“小节标题”。
- **推断与缺口**：说明哪些内容是推断，哪些问题不能从当前资料确认；必要时指出补充何种资料最有帮助。

简单事实问题可合并为一两段，但仍应保留来源标识。

## 约束

- 搜索命中只用于定位，只有实际读取到的原文内容才能作为依据。
- 不把选定范围外的常识、猜测或未核实内容伪装成笔记结论；用户要求补充外部背景时，应与笔记证据明确分开。
- 资料不足时明确说明“当前资料无法确认”，不要编造引文、标题或细节。
- 此技能只回答与分析，不移动、改写或创建笔记。
