# 学习文档生成

针对用户指定的知识库文档，生成一份结构化、可独立使用的学习文档。目标是让用户不翻原文也能抓住重点，并知道自己学到哪一步、下一步学什么。

## 工作方式

1. 先定位用户指定的文档：按文档名检索并用工具实际读取原文，确认覆盖了主要章节；不要只凭检索摘要就动笔。
2. 未指定文档时，先列出检索到的候选文档标题让用户确认，不擅自替用户选择。
3. 生成前识别文档类型（教程、论文、规范、实验记录等），据此调整学习文档的侧重点；模板参考本技能附加文件 `templates/学习文档模板.md`，可用 read_skill 的 file_path 读取。
4. 学习进度安排若用户未给约束，用「建议顺序」表达，不虚构截止日期。

## 产出结构

默认包含以下部分，可按文档体量裁剪：

1. **概览**：一段话说明原文讲什么、适合谁、读完能掌握什么。
2. **核心概念**：逐条列出关键术语/概念，附原文语境下的简明解释。
3. **分章要点**：按原文结构组织，每节给出要点摘要；重要结论注明出处（《文档标题》—「章节标题」）。
4. **自测清单**：5~10 个可用于检验掌握程度的问题，答案均可在原文找到依据。
5. **建议学习路径**：先学什么、后学什么，以及哪些部分可以快速略读。

## 约束

- 所有内容必须来自实际读取到的原文；原文没有的信息不得写入学习文档，确需补充外部背景时单独成节并注明「补充背景」。
- 引用结论时保留出处标识，不合并、不改写原文观点的含义。
- 原文存在错误或过时表述时如实转述并提示，不替原文修正事实。
- 只生成学习文档内容供用户保存，不直接修改或删除知识库中的任何文件。
