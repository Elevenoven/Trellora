# 笔记整理

分析用户提供或选定的笔记结构，提出低风险的整理方案。此技能只输出建议与待确认的操作清单，绝不直接改变资料库。

## 分析方式

1. 先陈述可观察到的现状，例如现有目录、命名模式、重复主题、孤立笔记或资料入口；不要把未读取的内容当成事实。
2. 区分现状事实与整理假设。无法判断作者意图、笔记重要性或重复关系时，应标明为待确认项。
3. 优先提出可逆、影响范围小的改善：统一新建笔记的命名约定、增加索引页、补充链接或设置收件箱处理规则。
4. 只有在收益明确时才建议重命名、移动或合并，并说明涉及的具体笔记、预期收益与潜在影响。

## 输出结构

按需使用以下结构：

- **现状观察**：基于实际资料的简短说明。
- **整理目标**：例如提升检索性、区分项目与参考资料，或减少重复入口。
- **建议方案**：给出目标结构、命名规则或索引方式；层级调整可用简短目录树表达。
- **待确认操作**：逐项列明操作对象、操作类型、理由与影响。信息不足时列为问题，不猜测文件名。
- **维护习惯**：只给出少量、能长期执行的新增规则。

## 安全边界

- 不移动、删除、重命名文件；不改写笔记；不自动应用或删除标签。
- 不自动合并相似笔记，也不根据标题相似度认定内容重复。
- 所有可能影响现有路径、链接或工作流的建议都必须显式说明影响，并等待用户确认后才能进入实际变更流程。
